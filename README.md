# Opportunity Knocks: Fantasy Sports Manager

Support and feedback for **Opportunity Knocks**, a free Chrome extension that puts real NFL usage data next to your ESPN fantasy football league: waiver targets, lineup checks, matchups, trades, byes and more, with optional league changes you confirm one at a time.

This repository is only for **issues**: bug reports and ideas. The extension's code is not here.

## Report a problem or suggest an idea

[Open an issue](https://github.com/lotaagulue/opportunity-knocks/issues/new/choose). Please include the extension version (in `chrome://extensions`) and what you expected to happen.

**Never post your ESPN cookies or login details**, and please don't include other managers' team names in screenshots. Issues here are public.
